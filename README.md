# Retail Sales Dashboard 

## Project Overview
This project is an interactive Retail Sales Dashboard developed using Microsoft Excel.
The purpose of this project is to analyze retail sales performance and provide meaningful business insights using data cleaning, Excel formulas, PivotTables, KPIs, and data visualizations.

## Business Objectives
The dashboard was created to answer key business questions such as:

- What are the total sales and total profit?
- Which region generates the highest sales?
- How do sales change month by month?
- Which product categories generate the most sales?
- Which categories generate the most profit?
- What is the order status distribution?
- Which products generate the highest sales?
- How do sales vary by salesperson?

## Key Insights
- North generated the highest regional sales.
- October recorded the highest monthly sales.
- Delivered orders represented the largest order-status category.
- The dashboard provides a comparison of sales performance across categories, regions, products, and salespeople.
- The overall profit margin was 16.42%.
